Mainframe

Points:

    “Big Iron”

    Still in active use (according to IBM)

    RAS = reliability, availability, servicability

    Uptime measured in years

    Question: Will they be replaced by clustered cloud servers?

Concepts:

    Mainframe:

        Large, expensive, highly reliable computers used for critical enterprise workloads.

        Handle massive numbers of transactions (e.g., banking, insurance, airline reservations).

    RAS:

        Reliability: minimal failures, robust error detection/correction.

        Availability: designed to stay up almost all the time; minimal downtime.

        Servicability: easy to maintain, diagnose, and repair without shutting down.

    Uptime in years:

        Mainframes can run continuously for years with only minor maintenance.

        Critical for systems where downtime is extremely costly.

    Cloud clusters vs mainframes:

        Cloud: many commodity servers networked together; scale out.

        Mainframe: one very powerful, very reliable system; scale up.

        Both coexist; some workloads migrate to cloud, others stay on mainframes for legacy, performance, or regulatory reasons.

Mainframes represent the high end of the computer zoo: extreme reliability and transaction capacity
