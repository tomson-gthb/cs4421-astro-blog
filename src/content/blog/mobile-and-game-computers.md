Mobile, Games, Industrial

Points:

    Sony PlayStation, Nintendo DS, etc.

    ARM Cortex-A.

    Tablets: Samsung Galaxy, etc.

    Closed: no USB or other connectivity (some devices).

    Connected: WiFi, Bluetooth.

    Higher-end mobile (with USB, Ethernet, etc.):

        Broadcom BCMxx SoC (Raspberry Pi).

        Intel “Cherry Trail” (Aaeon UP board).

Concepts:

    ARM Cortex-A:

        Application processors, designed for rich OSes (Android, Linux, iOS-like).

        More powerful than Cortex-M, with features like MMU (memory management unit) for virtual memory.

    Game consoles & handhelds:

        Custom SoCs (system-on-chip) often based on ARM.

        Optimized for graphics, media, low latency input.

    Tablets & smartphones:

        Run full mobile OSes, apps, browsers, multimedia.

        Need good performance and power efficiency.

    Closed vs connected:

        Some devices are “closed”: limited external interfaces, locked down for security/DRM.

        Others have WiFi, Bluetooth, USB, sometimes Ethernet for networking and peripherals.

    SoC (System on Chip):

        CPU cores + GPU + memory controller + I/O + sometimes modem on one chip.

        Examples: Broadcom BCM series, Intel Cherry Trail.

    Raspberry Pi, UP board:

        Single-board computers using mobile-class SoCs.

        Used for education, prototyping, small servers, IoT gateways.

This category sits between MCUs and full PCs: more powerful, runs complex OSes, but still power/size constrained.
